# Fuzzing Notes

## `unpack_fuzzer`

Consumes a small `GFZA` command archive. Each record carries a glyph payload that is written to a temporary file and then exercised through production file APIs: load, validation, render, unpack, atlas export, and manifest generation. Corpus entries are generated by `seed_corpus`.

Crash description: processing a structured glyph archive can crash during cached kerning lookup after a reload-style sequence with dense kerning and changed glyph ordering.

## `scene_fuzzer`

Consumes a text scene document with nested nodes and a stateful operation log. Inputs exercise scene traversal, handler registration, dispatch, deregistration, schema promotion, and export snapshots.

Crash description: A heap-use-after-free/type-confusion occurs in `scene_handler_dispatch_cached` when a handler route cached before schema promotion is dispatched after its slot has been reclaimed and assigned to a different handler type.
